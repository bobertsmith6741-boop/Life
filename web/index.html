How to use the .gpx (Mac / Windows) — and the honest caveats

Mac · Xcode (free):

  1. Make a throwaway Xcode project (any "App" template) and run it once on your iPhone (plugged in, Developer Mode on).
  2. Drag mockpilot.gpx into the project.
  3. Run on the device, then in the debug bar's location dropdown (or Debug ▸ Simulate Location) pick mockpilot. iOS now reports the moving track device-wide.

Windows · desktop tool: 3uTools (free) has a "Virtual Location" feature; iToolab AnyGo / Dr.Fone (paid) import a route/GPX. Plug the iPhone in and load the file.

⚠️ Reality check: Snap Map generally just shows whatever location the device reports, so this works for it. Life360 actively tries to detect spoofing and can show your circle a "location may be inaccurate" flag — realism helps it look human and avoids the teleport tell, but it can't guarantee Life360's dedicated detection won't catch the developer-image spoofing. Use on your own device.
